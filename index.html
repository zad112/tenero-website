Test network gamma · v0.4.0-gamma.1

An experimental proof-of-work coin, built to learn how these systems work.

A GPU proof of work (matmulhash v2) and Monero's newest privacy design, FCMP++ and Carrot, from the first block. Written in Rust, by one person.

This is a learning project, not a currency

  • Nothing on any Tenero network has any value, and the test network can be reset.
  • It is unaudited. The privacy code is unaudited as used here: Monero's FCMP++ libraries (only partly audited), a Carrot written in Rust by this project, and message signatures and payment proofs that are this project's own construction, reviewed by nobody.
  • The proof of work is new, unreviewed, and not claimed to be ASIC-proof.
  • Do not use any of it to hold anything you cannot afford to lose.

Inspired by Monero's design ideas; not affiliated with or endorsed by the Monero project.

How it works

The chain

A block every 60 seconds, aimed for. The difficulty is re-worked every block from the last 30 (LWMA), and a block's time must be later than its parent's.

Coins

Ticker TNR. 20 coins a block at first, halving every 525,600 blocks (a year), up to 20,000,000, then a tail of 0.5 a block. No premine: every coin is mined, the author's included.

Proof of work

Each attempt multiplies a 64 × 8192 matrix of 8-bit integers against columns gathered from a 4 GiB dataset, rebuilt every 100 blocks. The aim is to be limited by memory bandwidth, which GPUs are built for. That is an argument, not a proof.

What you pay

A spend proves with FCMP++ that its coin is one of all outputs on the chain; amounts are hidden with Bulletproofs+. Addresses are Carrot (they start TENg), with subaddresses and view-only wallets. On a young chain a spend hides among very few outputs.

Where you connect from

Since 0.4.0 a new payment travels a short random path of peers before it is announced (Dandelion++, Monero's design). Tor is optional, through a separate Tor program. With few nodes, the author's two seeds still see a lot.

The miner's fee

The project's miner gives 1% of its time (one minute in a hundred) to the author of the backend it uses: NVIDIA to the project's author, AMD to its contributor. The CPU has none. It is always shown and cannot be turned off. The addresses.

Measured on one RTX 5070 Ti: about 43,000 to 45,000 attempts a second. On a CPU, mining gamma is impractical. Everything else is in the consensus rules, the known issues and the threat model.

Get started

  1. Download only from the GitHub Releases page: a Windows zip, a Linux tar.gz, and a Linux AMD tar.gz for AMD cards. Check the download (below), or build it yourself with Rust. Read the release notes first.
  2. Run the wallet app, tenero-wallet-gui. It starts the node and the miner itself. The node needs about 4.3 GiB of free RAM. Everyone on gamma needs 0.4.0: older programs find no peers.
  3. Mine on an NVIDIA GPU (RTX 30 series or newer, a driver for CUDA 13), alone or in the test pool. AMD RX 7000 and 9000 cards work on Linux only, with ROCm 7, and nobody on the project has run that miner. The mining guide.

Your antivirus may call it a "coin miner". That is partly true: it includes a miner, which runs only when you start it. The files are not code-signed. Check the hash, or build from source.

Check a download

Download SHA256SUMS from the same release, put it next to the file, and compare. The two must match exactly.

Windows (PowerShell, in the folder with the files):

Get-FileHash .\tenero-0.4.0-gamma.1-windows-x64.zip -Algorithm SHA256
Select-String windows-x64 .\SHA256SUMS

Linux:

sha256sum -c SHA256SUMS --ignore-missing

This shows that the file is the one the release lists. It does not show that the release is safe: nothing here is audited.

Talk and notices

Questions, bug reports and hardware numbers: the Discord server. Nothing said there, or on this site, is an official notice. The only place a "stop mining" notice is posted is the pinned issue #1, and only the author can post there.
