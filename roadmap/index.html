Where it stands, and what is next

As of 11 October 2026. No date on this page is a promise. "Released" means published for people to try, not finished, reviewed or safe.

So far

WhenWhat
5–6 Oct 2026alpha (v0.1.0-alpha.1 to .4): the Rust node, miner and wallet on a first public network, with ring signatures and an interim output scheme that was not Carrot and gave no Monero-style privacy. Closed.
7 Oct 2026beta (v0.2.0-beta.1 to .4): a second seed and a mining pool. A flaw was found in the proof of work (a miner could reuse one memory read for many attempts) and fixed with the gathered attempt. Closed when gamma launched.
9 Oct 2026gamma launched (v0.3.0-gamma.1): a fresh chain with FCMP++ and Carrot from its first block, the gathered proof of work from block 0, and no premine.
11 Oct 2026v0.4.0-gamma.1: Dandelion++ for payments, optional Tor, the 1% miner fee, a contributed AMD miner for Linux (not run by the project), and fixes. Everyone had to upgrade: the network protocol changed. Both seeds became reachable through Tor.

Built

  • A node (pruned by default), a GPU and CPU miner, a command-line wallet and a wallet app with a window
  • A block explorer, a seed checker, a mining pool and a checker for pools
  • FCMP++ and Carrot from block 0: subaddresses, integrated addresses, view-only wallets, payment requests
  • Message signatures and payment proofs (this project's own construction, reviewed by nobody)
  • Dandelion++ and optional Tor; an encrypted channel between peers
  • About 1,170 automated tests, and the Rust checked bit for bit against an independent Python reference and Monero's own results

Next (no dates)

  • An independent review of the cryptography (this project's Carrot and signatures first) and of the proof of work, wanted before anything could carry value. None has happened.
  • A longer public test on gamma.
  • The seeds' .onion addresses built into the program, used only when you turn Tor on.
  • A remote wallet, for computers without the memory for a node.
  • More seeds run by people other than the author. Today there are two seeds and one operator.

A main network

The author plans to launch a permanent main network on 1 November 2026: a chain not meant to be reset, built on the gamma rules. That is an intention, not a promise. The date can move, and a launch would not make the software finished, reviewed or safe: it would still be unaudited, written by one person, with seeds run by one person. Put nothing into it that you cannot lose.

The full status, with what is measured and what is worked out: the README. What is known to be wrong: the known issues.
