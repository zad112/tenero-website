Questions

Short answers, with links to the longer ones. If yours is not here, ask on the Discord server.

The basics

Is it worth anything?

No. Nothing on any Tenero network has any value, and the project sells nothing: no coins, no tokens. It is a learning project by one person, and it is unaudited. Do not buy or sell it, and do not put anything into it that you cannot lose.

Will the chain be reset?

gamma is a test network and can be reset. If it is, the coins on it are gone. A permanent main network is planned for 1 November 2026, as an intention, not a promise (the roadmap). The earlier networks, alpha and beta, are already closed, and nothing moved from them to gamma.

Was there a premine?

No. The first block of gamma creates no coin. Every coin is mined, the author's included, and a test checks this. The 1% miner fee is a share of mining time, not coins made out of nothing (the fee).

Is it a Monero fork?

No. It is written from scratch in Rust, with its own proof of work. For privacy it uses Monero's newest design, FCMP++ through Monero's own Rust libraries, and Carrot addresses written here from the specification. It is inspired by Monero, and not affiliated with or endorsed by the Monero project.

Who runs it?

One person, zad112. The two seeds and the test pool are on two rented servers run by that same person. That is a weakness: the plan wants seeds run by several independent people, and anyone can add their own seed with --seed ip:port.

Running it

Why does my antivirus call it a "coin miner"?

Because it contains one. tenero-miner runs your GPU or CPU at full load, which is what those detectors look for, and the files are not code-signed. Nothing mines until you start it. Do not take anyone's word for what a file is: check its SHA-256 against SHA256SUMS (how), or build it from source. If you decide to trust it, exclude only its own folder, and only download from the GitHub Releases page.

Why does the node need 4.3 GiB of memory?

To check a block's proof of work, a node needs that epoch's 4 GiB dataset, the same one miners use. It holds one at a time and builds the next every 100 blocks, which pauses it for about 3 seconds. The dataset is what ties the proof of work to memory, which is the point of its design.

Which systems does it run on?

Windows 11 (the only Windows tried) and Linux (Ubuntu 22.04 or newer). There are no macOS builds. On Linux, the node, the pool and the command-line wallet have been run by hand; the Linux wallet app and the NVIDIA miner on Linux have not.

Does it work on my graphics card?

NVIDIA RTX 30 series or newer, with a recent driver: yes, but only a 16 GB card has been tried. AMD RX 7000 and 9000 on Linux: contributed and not run by anyone on the project in this version. Older cards and macOS: no. The mining guide.

How do I back up my wallet?

Write down the 24 words the wallet app shows when you create a wallet, on paper, and keep them safe. They are the wallet: anyone who has them has your coins, and with them you can restore it anywhere. The password only locks the wallet file on that computer.

Should I let other nodes connect to me?

It helps the network ("Let other nodes connect to me" in the app's Settings, off by default), because new nodes then do not all depend on the seeds. But it needs a port forwarded on your router, it lets strangers connect to your computer, and the software is unaudited. Your choice.

Privacy

How private is it, really?

Less than the design promises, for now:

  • A small crowd. A spend hides among all the outputs on the chain, but a young chain has few, almost all of them block rewards of a few miners. The first spends on gamma hide among very few people, and timing still leaks.
  • Not audited as used. Monero's FCMP++ libraries are only partly audited and not yet on Monero's main network; this project's Carrot and its glue are not audited at all; its message signatures and payment proofs are its own construction, reviewed by nobody.
  • Where you connect from. Dandelion++ hides which node a payment started from (in a simulation, a spy on every node named the sender of 6 payments in 24, against 23 without it). With few nodes, mostly through the author's two seeds, they still see a lot. Tor hides your IP address.
How do I use Tor?

Install Tor separately (the Tor Browser, or the Tor Expert Bundle; Tenero contains no Tor code), then in the wallet app's Settings, Tor, type its SOCKS port (127.0.0.1:9150 for the Tor Browser, 127.0.0.1:9050 for the bundle). Tick "Every connection through Tor" if peers must never learn your IP address. It is slower. RUNNING.md, "Tor".

Does this website track me?

No cookies, nothing loaded from other sites, and the server keeps no visitor IP addresses in its log. On the pool page, an address you type is hashed in your browser and never sent anywhere.

Problems

Where are official notices posted?

Only in the pinned issue #1, where only the author can post. Not on Discord, and not on this site. Anything claiming to be a notice anywhere else is not from the project.

I found a security problem.

Please report it privately, through the repository's Security tab ("Report a vulnerability"). Anything else: an issue, or the Discord.

What is known to be wrong?

It is written down, including what nobody has fixed: the known issues and the threat model.

Tenero is a learning project: unaudited, not for real value. This site sets no cookies and loads nothing from other sites.
